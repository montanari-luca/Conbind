# Web Search

> Search the web from the launcher: start your search with `$`.

## What it does

Type `$` followed by what you want to look up, for example `$Learn java` or `$ rust lifetimes`. Conbind shows a **Search the web** row; press `Enter` and your default browser opens the results. Conbind itself makes no network request: it only hands the address to your browser.

## How to use it

1. Open Conbind and type `$` and your search.
2. Press `Enter`. The launcher hides and your browser opens the results page.

## Choosing the search engine

Google is used by default. To change it, open **Settings → Advanced → Web search engine** and pick Google, DuckDuckGo, Bing, or Brave Search.

## Tips

- **A space after `$` is optional.** `$java` and `$ java` are the same search.
- **It can be switched off** like any other built-in feature, if you want `$` to behave like any other character.
